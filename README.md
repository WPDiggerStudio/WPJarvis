# WPJarvis 🧠

WPJarvis is a Laravel-inspired, MVC-structured framework for building modern, maintainable WordPress plugins.

## 🚀 Features

- MVC architecture
- Blade (or Twig) templating
- Custom routing system
- Service provider structure
- Easy CPT, taxonomy, AJAX & admin menu registration
- Composer & PSR-4 ready
